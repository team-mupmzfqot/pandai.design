# Pandai Design System 2026

Welcome to the Pandai Design System for 2026! This project aims to provide a comprehensive set of components, tokens, and utilities to streamline the design and development process for Pandai applications.

## Overview

The Pandai Design System is built with React and focuses on creating reusable components that adhere to our design principles. It includes a variety of UI components, design tokens for consistent styling, and utility functions to enhance development efficiency.

## Project Structure

```
pandai-design-system-2026
├── src
│   ├── components          # Reusable UI components
│   ├── tokens              # Design tokens (colors, typography, spacing)
│   ├── utils               # Utility functions
│   └── index.ts            # Entry point for the design system
├── docs                    # Documentation files
├── .github                 # GitHub workflows
├── package.json            # Project metadata and dependencies
├── tsconfig.json           # TypeScript configuration
├── vitest.config.ts        # Vitest configuration
└── README.md               # Project documentation
```

## Getting Started

To get started with the Pandai Design System, follow these steps:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/your-username/pandai-design-system-2026.git
   cd pandai-design-system-2026
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run the Development Server**
   ```bash
   npm start
   ```
